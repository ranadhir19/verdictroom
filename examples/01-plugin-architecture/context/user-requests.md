# Issue tracker themes, trailing 12 months

- 214 open feature requests. The largest cluster (63 issues) asks for
  custom input formats: proprietary appliance logs, vendor CSV
  variants, one-off JSON shapes. Maintainers have closed 41 of these
  as "cannot prioritise" in the past year.
- Second cluster (38 issues): custom exporters — ticketing systems,
  chat webhooks, internal dashboards.
- At least 9 users describe maintaining private forks solely to add
  one parser or one exporter. Two forks have diverged enough that
  their fixes no longer cherry-pick back.
- Requests for new built-in analysis types are comparatively rare
  (17 issues) and usually satisfiable in core within one release.
- No user has asked for a plugin marketplace, signing, or sandboxing;
  the asks are uniformly "let me add my own parser/exporter".
