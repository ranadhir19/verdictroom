# Usage profile and cost structure

- 120,000 monthly active users. Usage is heavily skewed: the top
  8% of users generate about 70% of sync traffic and storage.
- Median user keeps ~40 notes, opens the app 9 days a month, and
  has never hit a free-tier limit.
- Server cost per casual user is a few cents a month; per heavy
  user it reaches roughly $0.90/month at current architecture.
- The features users say they would pay for, from an in-app survey
  (n≈3,100): unlimited storage (41%), cross-device sync history
  (33%), automation/shortcuts (18%), themes and cosmetics (12%).
  Percentages overlap; respondents could pick two.
- Support load today is ~30 tickets a month, handled by the founder.
  Billing confusion ("why was I charged twice", "what does this
  include") is already the second-largest ticket category despite
  there being no paid tier yet.
